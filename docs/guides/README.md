# InfoMark guides

This directory contains the InfoMark documentation as a plain, interlinked
collection of Markdown files. Start with the overview and then move to the
guide that matches your role.

- [Overview](overview.md) — what InfoMark is, its design choices, a quick-start
  for spinning up an instance, and a tour of the system's parts (server,
  workers, console, and the embedded web interface).
- [Administrator's guide](administrator.md) — installing and configuring a
  server, managing roles and permissions, running auto-tests, assigning
  exercise groups, backing up and restoring the database, and exposing metrics.
- [Tutor's guide](tutor.md) — writing auto-tests for student submissions, with
  worked examples for Java 11, Python 3, and C++.
- [Developer's guide](developer.md) — building the React frontend and the Go
  backend from source and running the unit-test suite.
- [Console](console.md) — the server-side `infomark console` command and where
  its commands are documented across the other guides.
- [Queries](queries.md) — handy SQL snippets for statistics over the InfoMark
  database.
